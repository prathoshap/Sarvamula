THE GATE FIX (this is the headline)
  render_batch.py gate() trimmed clip onsets with thresholds written for STOP
  bursts: first 20ms frame over voice=0.08, back-walk while over sil=0.012, keep
  30ms lead, then fade in from ZERO over 15ms. Correct for a stop (real closure
  silence). Wrong for any SONORANT onset — vowel, semivowel य/व/र/ल, nasal — whose
  attack ramps up gradually and so falls under the floor.
  Measured on u05 यतो: the old gate started at 290ms, the fixed one at 170ms.
  The 120ms it was discarding had RMS -27.7 dBFS and peak -13.9 dBFS — plainly
  audible speech, not padding. Confirmed by ear 2026-08-02.

  Fix: soft_onset() in render_batch.py classifies by onset type —
       _STOPS = kKgGcCjJwWqQtTdDpPbB (SLP1); everything else takes the gentle path
       (low 0.006 floor, no fade-in). Previously only ś/ṣ/s/h were spared.
  Box backup of the pre-fix file: ~/Prathosh/production/render_batch.py.bak-presonorant

  Onset class over this block (6 of 10 changed behaviour — exactly the units that
  used to need the primer):
      u01 ज stop | u02 ब stop | u03 उ SOFT | u04 इ SOFT | u05 य SOFT
      u06 य SOFT | u07 च stop | u08 प stop | u09 य SOFT | u10 इ SOFT
  Verified post-render: all 4 stop-onset clips have sample[0] == 0.0 exactly (fade
  applied, as intended); all 6 soft-onset clips have sample[0] != 0 (attack kept).

THE ॐ PRIMER IS RETIRED
  It was a workaround for the gate bug, not for a model limitation. build_shard.py
  now has PRIMER = "" and SEED = {} (the u04 seed-62 override was compensating for
  the same bug). The model still cannot voice a LONE ॐ — that is a separate, real
  quirk — so the sutra's pranava is still the spliced human exemplar, by choice.
